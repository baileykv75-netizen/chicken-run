# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送小游戏。玩家需要保护 10 只小鸡，阻止狐狸把它们带出农场，并坚持到天亮。

## 当前版本

阶段 2.1：移动端操控与大地图重构。

- 玩家移动、自动挥剑与局内升级；
- 10 只小鸡与三类狐狸；
- 手机任意触点动态摇杆；
- 扩大后的世界地图与平滑跟随镜头；
- 狐狸死亡即时清理；
- 升级界面稳定性修复；
- 竖屏手机视野与 HUD 优化；
- 3 分钟胜负结算；
- 本地最佳纪录与音效开关。

## 操作

- 电脑：WASD 或方向键；
- 手机：按住游戏画面任意位置生成摇杆，并以初始触点为中心拖动；
- 守卫者靠近狐狸时会自动攻击。

## 运行方式

直接打开 `index.html`，或使用任意静态服务器运行仓库根目录。

# Chicken Run / 小鸡快跑

一款无需安装、打开网页即可游玩的可爱风 HTML5 护送生存小游戏。

在线地址：

`https://baileykv75-netizen.github.io/chicken-run/`

## 操作

- 电脑：WASD 或方向键移动；
- 手机/平板：使用左下角虚拟摇杆；
- 玩家靠近狐狸后会自动挥剑；
- 击败狐狸获得经验，升级时三选一强化；
- 保护 10 只小鸡并坚持 3 分钟。

## 当前内容

- 10 只会跟随、逃跑并可能被抓走的小鸡；
- 普通、迅捷、蛮力三类狐狸；
- 8 种局内强化；
- 等级、经验、暂停、胜负结算；
- 本地最佳纪录；
- 自适应电脑和移动设备；
- 无第三方依赖，无构建步骤。

## 本地运行

直接打开 `index.html`，或使用任意静态文件服务器访问仓库根目录。

## 发布

仓库已配置为从 `main` 分支的 `/ (root)` 通过 GitHub Pages 发布。

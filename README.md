# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送与无尽生存小游戏。玩家选择长剑、长枪或大锤，在不断增强的狐狸潮中保护 10 只小鸡，并挑战最长生存时间。

## 当前版本

阶段 4B：机制技能与升级刷新系统。

- 正向无尽计时与最长生存纪录；
- 危险等级、周期狐狸潮和前期缓冲；
- 电脑键盘与手机动态虚拟摇杆；
- 大地图与平滑跟随镜头；
- 长剑、长枪、大锤三武器；
- 每次升级一次免费刷新；
- 鸡不可貌相、布鲁斯、我的刀盾、养鸡邪修、翻过鸡鸣坡；
- 世界线技能“结束冷兵器时代”；
- 冷兵器可转化为左轮、步枪或霰弹枪；
- 三级牧鸡铃、暂停、结算与重新开始。

## 三武器定位

- **长剑**：两斩击败普通狐狸，近距离稳定扇形清群；
- **长枪**：远程投出与召回双段伤害，风险低但击杀较慢；
- **大锤**：有抬锤前摇，近距离一击爆发并附带眩晕与强击退。

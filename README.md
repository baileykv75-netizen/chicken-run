# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送小游戏。玩家需要保护 10 只小鸡，阻止狐狸把它们带出农场，并坚持到天亮。

## 当前版本

阶段 3：三武器战斗框架。

- 独立大地图与平滑跟随镜头；
- 手机端任意触点动态虚拟摇杆；
- 10 只小鸡与三类狐狸；
- 长剑：扇形范围斩击；
- 长枪：投出与召回双路径伤害，每隔数次攻击触发突进；
- 大锤：范围砸地、强击退与眩晕；
- 局内经验升级与通用/武器专属强化；
- 3 分钟胜负结算；
- 本地最佳纪录、暂停和音效开关。

## 操作

- 电脑：WASD 或方向键移动；
- 手机：按住游戏画面任意位置生成虚拟摇杆，拖动控制方向；
- 攻击自动锁定附近狐狸；
- 开局可选择长剑、长枪或大锤。

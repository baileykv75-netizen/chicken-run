# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送与无尽生存小游戏。玩家选择长剑、长枪或大锤，在不断增强的狐狸潮中保护 10 只小鸡，并挑战最长生存时间。

## 当前版本

阶段 4C：武器回调、性能优化与首次超限。

- 正向无尽计时与最长生存纪录；
- 危险等级、周期狐狸潮和前期缓冲；
- 电脑键盘与手机动态虚拟摇杆；
- 大地图与平滑跟随镜头；
- 长剑、长枪、大锤三武器；
- 长剑第三击自动释放剑气；
- 长枪恢复高速往返、较高伤害和周期突进；
- 大锤保留高爆发范围割草定位；
- 每次升级一次免费刷新；
- 鸡不可貌相、布鲁斯、我的刀盾、养鸡邪修、翻过鸡鸣坡；
- 世界线技能“结束冷兵器时代”；
- 冷兵器可转化为左轮、步枪或霰弹枪；
- 新增“助我破鼎”与三武器双路线超限；
- 批量范围伤害、粒子上限、自适应低特效与镜头外绘制裁剪；
- 三级牧鸡铃、暂停、结算与重新开始。

## 三武器定位

- **长剑**：高频扇形近战，每第三击释放中距离剑气；
- **长枪**：高速投出与召回双段穿透，伤害和机动能力较强；
- **大锤**：有抬锤前摇，单次范围爆发、眩晕与击退最强。

## 超限路线

获得“助我破鼎”后，通过击败狐狸和救鸡积攒鼎火。鼎火满后可以二选一：

- 长剑：无死角 / 追光；
- 长枪：贯日 / 游龙；
- 大锤：天崩 / 镇场。

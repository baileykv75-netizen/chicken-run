# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送与无尽生存小游戏。玩家选择长剑、长枪或大锤，在不断增强的狐狸潮中保护 10 只小鸡，并挑战最长生存时间。

## 当前版本

阶段 4D-2：第一轮角色与武器美术替换。

- 正向无尽计时与最长生存纪录；
- 危险等级、周期狐狸潮和前期缓冲；
- 电脑键盘与手机动态虚拟摇杆；
- 大地图与平滑跟随镜头；
- 长剑、长枪、大锤三武器；
- 长剑第三击自动释放剑气；
- 长枪高速往返、较高伤害和周期突进；
- 大锤高爆发范围割草定位；
- 每次升级一次免费刷新；
- 鸡不可貌相、布鲁斯、我的刀盾、养鸡邪修、翻过鸡鸣坡；
- 世界线技能“结束冷兵器时代”；
- 冷兵器可转化为左轮、步枪或霰弹枪；
- “助我破鼎”与三武器双路线超限；
- HUD 构筑按钮、暂停构筑摘要和跨局技能图鉴；
- 鸡中龙凤、守望相助、技术跃迁、学成归来四种隐藏组合；
- 增强后的攻击、升级、组合与狐狸潮音效；
- 守卫者、小鸡、三类狐狸、布鲁斯和三把冷兵器使用原创 SVG 贴图；
- 批量范围伤害、粒子上限、自适应低特效与镜头外绘制裁剪。

## 第一轮美术升级

- **守卫者**：独立角色贴图，移动时轻微起伏，武器随朝向旋转；
- **小鸡**：普通鸡与觉醒鸡使用不同造型，觉醒鸡带红色头巾；
- **狐狸**：普通、迅捷、蛮力拥有不同体型和轮廓，不再只靠换色区分；
- **布鲁斯**：使用原创牧场犬造型；
- **武器**：长剑、长枪和大锤拥有独立贴图；
- **兼容性**：SVG 未加载完成或加载失败时自动使用旧版 Canvas 几何绘制。

## 三武器定位

- **长剑**：高频扇形近战，每第三击释放中距离剑气；
- **长枪**：高速投出与召回双段穿透，伤害和机动能力较强；
- **大锤**：有抬锤前摇，单次范围爆发、眩晕与击退最强。

## 超限路线

获得“助我破鼎”后，通过击败狐狸和救鸡积攒鼎火。鼎火满后可以二选一：

- 长剑：无死角 / 追光；
- 长枪：贯日 / 游龙；
- 大锤：天崩 / 镇场。

## 构筑与图鉴

- 游戏中点击 HUD 右上角的书本按钮查看当前构筑；
- 暂停界面会展示武器、等级、超限路线和已获得技能；
- 主菜单可以打开技能图鉴；
- 升级时见过的技能会记录在浏览器本地；
- 机制技能满足条件时会触发隐藏组合并给出明确提示。

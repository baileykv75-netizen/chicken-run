# Chicken Run

《小鸡快跑》是一款可爱风 HTML5 网页护送与无尽生存小游戏。玩家选择长剑、长枪或大锤，在不断增强的狐狸潮中从一只小鸡开始建立鸡群，并挑战最长生存时间。

## 当前版本

当前阶段：**4H 随机事件与风险奖励**。

阶段 4G：精英狐狸与赤尾狐王（基于 4F 动态难度导演）。

- 潜行狐狸：半透明潜行、接近鸡群后预警现身；
- 冲锋狐狸：地面直线预警、冲锋、短暂恢复；
- 号令狐狸：给周围狐狸短时加速，并召集少量援军；
- 赤尾狐王：首次约 3 分钟登场，横扫、冲锋、召唤、半血强化、击败后回血；
- Boss 血条和低饱和手绘卡通精英剪影；精英与支援数量遵循现有性能上限。

此前 4F 功能：

- 新增玩家实际危险系数（0–100），根据清怪效率、鸡群安全、受伤及近身狐狸评估；
- 新增每 120 秒 30/60/30 秒的休整、有威胁、困难难度节奏；
- 每 5 秒采样、每 15 秒调节未来刷怪压力，保留高强度构筑的割草感；

## 升级节奏

- 初次升级只需要 3 点经验；
- 经验需求采用更平缓的成长曲线；
- 常规经验获取基础提高 50%；
- 危险等级提高后会获得额外经验倍率；
- 每击败 8 只狐狸获得一次割草节奏奖励；
- 一次跨越多级时，每一级都会依次提供独立强化选择与刷新机会。

## 长枪成长

- **枪出如林**：每次增加一支长枪，普通成长最多同时投出 5 支；
- **破阵枪锋**：投出与召回伤害提高，并增加穿透数量；
- **回马增势**：重点强化召回伤害、飞行速度和攻击循环；
- **七进七出**：提高突进频率、距离和路径伤害；
- **贯日**：额外增加一支长枪，使超限状态最高达到 6 支，并强化侧枪伤害；
- **游龙**：收紧枪阵角度并提高攻击频率；
- **枪械继承**：转化为步枪后，长枪数量会转化为多条射击弹道，并可通过“齐射机匣”继续成长。

## 美术升级

### 角色与武器

- **守卫者**：独立角色贴图，移动时轻微起伏，武器随朝向旋转；
- **小鸡**：普通鸡与觉醒鸡使用不同造型，觉醒鸡带红色头巾；
- **狐狸**：普通、迅捷、蛮力拥有不同体型和轮廓，不再只靠换色区分；
- **布鲁斯**：使用原创牧场犬造型；
- **武器**：长剑、长枪和大锤拥有独立贴图。

### 场景与界面

- **场景**：鸡舍、池塘、草垛和地图边缘围栏使用原创轻量 SVG；
- **地面**：增加草叶纹理、花草、土路细节和安全区域高光；
- **难度氛围**：危险等级提高后地图会出现轻微暮色变化；
- **主菜单**：小鸡与武器选择直接使用项目贴图；
- **升级卡**：不同技能稀有度拥有不同图标底座；
- **狐狸潮**：使用独立警示牌样式与弹入动画；
- **兼容性**：关键 SVG 未加载时会自动使用旧版 Canvas 几何绘制。

## 三武器定位

- **长剑**：高频扇形近战，每第三击释放中距离剑气；
- **长枪**：高速往返双段穿透，后期依靠伤害、枪数、召回和突进形成枪阵割草；
- **大锤**：有抬锤前摇，单次范围爆发、眩晕与击退最强。

## 超限路线

获得“助我破鼎”后，通过击败狐狸和救鸡积攒鼎火。鼎火满后可以二选一：

- 长剑：无死角 / 追光；
- 长枪：贯日 / 游龙；
- 大锤：天崩 / 镇场。

## 构筑与图鉴

- 游戏中点击 HUD 右上角的书本按钮查看当前构筑；
- 暂停界面会展示武器、等级、超限路线和已获得技能；
- 主菜单可以打开技能图鉴；
- 升级时见过的技能会记录在浏览器本地；
- 机制技能满足条件时会触发隐藏组合并给出明确提示。

## Phase 4H：牧场随机事件

- 保持 **10 只小鸡开局**，单鸡开局留到 4I 再做。
- 五种可选随机事件：迷路的小鸡、牧场补给车、狐狸盗宝贼、临时避难所和神秘宝箱。
- 第一场事件约45秒后出现，后续隔60–80秒；地图指示和计时帮助主动探索。
- 完成事件可补充失去的小鸡、获得生命或经验，神秘宝箱可选择普通奖励或更高风险挑战。
- Boss 战期间不会强制与事件叠加，保持既有动态难度和敌人上限。
- 事件 UI 采用柔和低饱和配色，电脑版与手机触屏共用交互。

## Phase 4I：从一只小鸡开始

- 每局开局只有 1 只小鸡，**不提供新手保护期**；原有武器攻击范围、前摇与玩家走位决定护送效果。
- 不再按等级自动孵化：地图上定期出现鸡蛋，普通小鸡靠近后自动驮起，必须护送到左上方鸡棚才能孵化；4H 迷路小鸡救援仍可获得新伙伴。
- 鸡群最多 10 只；达到上限后救援事件继续提供替代经验奖励。无需额外职业、资源、库存或小鸡属性菜单。
- 新孵化和救援的小鸡不增加专门的无敌时间，现有技能本身的护盾/觉醒能力保持有效。
- 修改 4F 动态难度的鸡群保护逻辑：开局少于 3 只小鸡不再直接被判定为濒危；危险保护仍可由生命值下降和实际鸡群减员触发。
- 新增 `tests/phase4i-smoke.test.js` 验证初始数量、鸡蛋拾取、鸡棚交付、双重损失、刷新间隔、鸡群上限和重开重置。

### Phase 4I 蛋护送机制补充

- 第一枚蛋约 75 秒后出现；野外蛋每次只存在 1 枚，未拾取约 50 秒消失；交付、丢失、过期之后再间隔 90–120 秒刷新下一枚。
- 普通小鸡靠近鸡蛋时自动驮起；玩家负责带队返回 **地图左上方已有的鸡棚**，距离鸡棚 105 游戏世界单位内即可自动孵化。
- 如果狐狸只是抓住运蛋小鸡，玩家仍可追击救回；如果狐狸成功将其带出地图，**小鸡与鸡蛋同时损失**。
- 已觉醒或侦察的小鸡不能担当运蛋小鸡；普通小鸡在运蛋过程中获得觉醒等不可抓状态时会自动放下蛋，避免无风险运输。
- 此机制不增加新手保护时间，不增加新货币、职业或复杂界面；鸡群总上限继续为 10 只。
